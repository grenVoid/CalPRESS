# CalPRESS-release.apk
A personalized calculator application with calculation history and local SQLite storage.

# CalPRESS Summary
- CALPRESS is a personalized calculator application designed to provide a clean and convenient way to perform mathematical calculations. The application features a custom calculator interface, a dedicated calculation display, and a built-in history system for reviewing previous calculations. It also uses SQLite for local storage, allowing calculation history to be saved and managed directly within the application.

# CalPRESS Features
- Basic Calculator Operations — Perform common mathematical calculations using a dedicated keypad.
- Calculation Display — Shows the current input and calculation result in a large display area.
- Percentage Calculation — Includes a percentage function.
- Delete / Backspace — Remove the most recent input when correcting a calculation.
- AC / Clear — Clear the current calculation.
- Calculation History — View previously recorded calculations through the History section.
- Clear History — Remove saved calculation history.
- SQLite Local Storage — Stores calculation history locally using SQLite.
- Custom User Interface — Uses a custom dark-themed layout with branded app and creator information.
- Responsive Keypad Layout — Uses a structured calculator keypad for the main operations.
